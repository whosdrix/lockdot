# Changelog

## 0.1.0 (unreleased)

First release.

- `init`, `set`, `get`, `unset`, `list`, `edit`, `run`, `export`, `import`
- Share with `add-member` using age keys, SSH keys or `github:username`
- `remove-member` rotates the data key and re-encrypts every value
- `check` for CI, with `.env.example` support
- Readable `git diff` through a textconv driver
- Per-environment files with `-e prod`
